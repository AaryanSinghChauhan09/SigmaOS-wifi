# SigmaOS-wifi

> **SigmaOS Wi-Fi Subsystem** — Wireless device enumeration, firmware lifecycle, WPA3/IWD integration, and network link monitoring.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.

## Quickstart

```bash
cargo build --release
cargo test
```
